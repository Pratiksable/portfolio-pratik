# Earth textures

- `day.jpg`: 4096 x 2048 Earth imagery, copied from the example folder of the
  `three-globe` npm package (v2.45.6, MIT licence).
- `night.jpg`: 4096 x 2048 night-side lights, from the same folder.

The MIT licence covers the package's code. It does not document where these
images came from. They appear to be NASA Blue Marble imagery, which NASA
generally publishes as public domain, but this has not been verified.

Before the site ships, confirm the source and licence of both images, or
replace them with a source whose licence is recorded here.
